# 🔑 币安 Alpha curl 获取插件

自动捕获币安余额接口的完整 `curl` 命令，一键复制使用。

---

## 安装步骤

### 第一步：下载插件

点击右上角 **Code → Download ZIP**，解压到任意位置（推荐桌面）。

> ⚠️ 解压后的文件夹**不能删除、不能移动**，Chrome 每次启动都需要读取它。

---

### 第二步：打开扩展管理页

在 Chrome 地址栏输入并回车：

```
chrome://extensions
```

---

### 第三步：开启开发者模式

页面**右上角**找到「开发者模式」开关，点击打开（变蓝即可）。

---

### 第四步：加载插件

点击左上角出现的「**加载已解压的扩展程序**」→ 选择刚才解压的文件夹 → 点「选择」。

Chrome 工具栏右上角出现 **BA** 图标，安装成功 ✅

---

## 使用方法

1. 打开 [binance.com](https://www.binance.com) 并登录账号
2. 点击右上角 **BA** 图标
3. 点击「**开始监听**」——插件自动跳转到币安 Alpha 页面并捕获余额接口请求
4. 图标变为绿色 **✓** 表示捕获成功
5. 再次点开插件，点「**复制 curl 命令**」粘贴到终端使用

---

## 常见问题

**Q：点击「开始监听」提示"请先切换到币安页面"？**  
A：需要先打开任意一个 binance.com 的页面，再点插件开始监听。

**Q：图标一直没变成 ✓？**  
A：点击「停止监听」后重新开始，确保已登录币安账号。

**Q：Chrome 提示「已停用开发者模式扩展程序」？**  
A：点击弹窗中的「重新启用」即可。

---

## ⚠️ 安全警告

生成的 `curl` 命令包含你的**账户登录凭证（Cookie + Token）**，具有与登录账号等同的权限。

**请勿截图或发送给任何人，一旦泄露他人可直接操控你的账户，造成不可挽回的财产损失。**
